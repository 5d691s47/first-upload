# 한 입의 기억 — 실행과 AI 연결

## 현재 구현
- 모바일 카메라 촬영/사진 선택 → 미리보기 → 전송 동의 → AI 분석 → 음식명·이모지·칼로리·감정 수정 → 식탁 → 먹이기 → 기록.
- 사진은 브라우저에서 1280px 이내 JPEG로 변환하며 기록에 저장하지 않습니다.
- AI는 사진 속 전체 식사를 하나의 메모로 추정합니다. 여러 접시는 추정 설명을 확인하고 직접 수정하세요.
- 첫 화면의 음식과 기록 화면의 저장된 음식 모두 수정 가능합니다.
- 아이콘화는 음식에 맞는 이모지를 선택하는 방식입니다. 개별 색연필 이미지 생성은 포함하지 않습니다.

## 실행
Node.js 20 이상에서 이 폴더를 열고 `npm start` 후 http://localhost:3000 접속.
서버 환경 변수에 OPENAI_API_KEY와 OPENAI_MODEL을 설정합니다. OPENAI_MODEL에는 계정에서 사용 가능한 이미지 입력·Responses API·구조화 출력 지원 모델 ID를 지정하세요.
키를 HTML, JS, Git 저장소에 작성하거나 채팅에 붙여넣지 마세요.
키/모델이 없으면 UI는 작동하지만 AI 분석은 503과 안내 문구를 반환합니다. 실제 AI 요청은 현재 검증하지 않았습니다.

## 배포
- Node 서버 실행과 HTTPS를 지원하는 호스팅에 이 폴더를 배포하고 시작 명령을 npm start로 설정합니다. PORT 환경 변수를 지원합니다.
- 호스팅의 비밀 환경 변수로 키와 모델을 설정해야 합니다. 정적 HTML만 배포하면 AI 분석은 작동하지 않습니다.
- 모바일 카메라는 브라우저/기기에 따라 촬영 또는 파일 선택으로 열립니다. 실제 기기에서 HTTPS로 확인하세요.
- 분석 호출은 API 사용료가 발생합니다. 공개 배포 전 사용자 인증, 사용자별 한도, 제공자 예산 제한을 추가하세요. 현재 IP 한도는 서버 메모리에만 있어 다중 서버/프록시 환경의 공용 제한으로 사용할 수 없습니다.
- 기록은 현재 브라우저 localStorage에만 있습니다. 도메인 변경 시 이전되지 않으며 기기 간 동기화는 없습니다. 동기화에는 로그인과 데이터베이스가 추가로 필요합니다.
- 원본 사진은 앱 서버에서 보관하거나 로그에 남기지 않으며 분석 시 OpenAI로 전송됩니다. store:false는 제공자의 모든 데이터 보존이 없다는 의미는 아닙니다. 공개 시 개인정보 안내를 마련하세요.
- 사진만으로 양과 조리법을 확정할 수 없어 칼로리는 추정치입니다. 분석 결과를 검토하고 수정한 값으로 기록합니다.

## 확인
`npm test` — 입력 검증, 서버 미설정 안내, 비공개 파일 접근 방지 확인.
